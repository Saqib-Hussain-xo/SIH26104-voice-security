# Known Limitations (Initial Stage)

1. The initial system will **not intercept normal cellular calls**.
2. Pretrained model performance must be evaluated under Indian-language, accent, noise, compression, and telephony conditions.
3. Model scores must **not** automatically be described as calibrated fraud probabilities.
4. Multilingual support will initially be limited and must be evaluated properly.
5. The MVP is **not** a production banking/telecom security product.
